# UPSkills 🎓

A complete **Learning Management System (LMS)** website with three different roles: **Students**, **Instructors**, and **Admin**.  
This platform allows users to register, learn, create courses, take quizzes, and handle payments securely.

---

## 🌟 Tech Stack

- **Frontend:** React, Tailwind CSS, Axios  
- **Backend:** Node.js, Express  
- **Database:** MongoDB  
- **Authentication & Security:** JWT, bcrypt  
- **Payments:** Razorpay (Test Mode)  
- **Notifications & Alerts:** SweetAlert2

---

## ⚡ Features

- User **Authentication** & **Authorization**  
- Multi-role support: **Students**, **Instructors**, **Admin**  
- Quizzes for students to assess knowledge  
- Notifications for important updates  
- Payments integration (Razorpay in test mode)  

---

## 👥 User Roles

| Role       | Access & Permissions |
|------------|-------------------|
| Students   | Enroll in courses, take quizzes, view progress |
| Instructors | Create & manage courses, view enrolled students |
| Admin      | Manage users, courses, and overall platform settings |

1. **Clone the repository** and move to the parent `UPSkills` folder:


2. **Backend**

npm install
npm run dev

3. **Frontend**
cd frontend/upskills
npm install
npm run dev
